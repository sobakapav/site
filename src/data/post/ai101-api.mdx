## <a name="anchor1" />Что такое API

Если совсем на пальцах, то API (Application Programming Interface)  — это интерфейс, только не для людей, а для программ.

Да, им тоже нужен интерфейс, потому что они взаимодействую друг с другом. Вскяий раз, когда вы, например, покупаете билеты в приложении, приложение обращается к билетному сайту. И делает это по API.

## <a name="anchor2" />При чем тут AI
Поскольку AI — тоже программы, им проще и быстрее общаться с другими системами через их API. Большинство AI вполне способны открыть сайт и ввести логин и пароль, но на это у них уйдёт значительно больше времени и токенов, чем при обращении через API.

Кроме того, API-ключи с ограниченными правами мешают AI, с их склонностью к галлюцинациям, сделать что-нибудь дурацкое и вредоносное.

## <a name="anchor3" />Что такое API-ключ
API-ключ или API-токен — это буквенно-цифровой код, который позволяет другим приложениям пользоваться API.

Как логин и пароль у пользователей-людей, только API-ключ можно настроить, выдав ему строго ограниченный набор разрешений. Например, разрешить только читать данные. 

Некоторые системы для безопасности выдают ключи только на ограниченный срок. Через день или через месяц такой ключ превратится в тыкву.

А если ключ скомпрометирован — его можно легко и быстро заблокировать.

## <a name="anchor4" />Для чего это вам
Чтобы другие программы могли пользоваться вашим аккаунтом AI, для них нужно будет создать API-токен.

Чтобы можно было отследить, какая именно программа сколько употребила токенов, рекомендуется для каждой из них создавать отдельный API-ключ.

## <a name="anchor5" />Как получить API-ключ для ChatGPT
1. Залогиньтесь на OpenAI Platform, используя тот же аккаунт, что и в обычный OpenAI.
2. Нажмите ‘Create new secret key’ на странице API-ключей.
3. Задайте имя ключа.
4. Система создаст буквенно-цифровой код (токен). Скопируйте его и сохраните в безопасном месте. Больше вам его не покажут, и если потеряете — придется выпускать новый.

<a href="/images/articles/ai101-api/5.png" target="_blank">![Собака Павлова • Азбука AI • Как AI общаются с другими программами](~/assets/images/articles/ai101-api/5.png)</a>

## <a name="anchor6" />Как получить API-ключ для Gemini
1. Включите VPN. Выберите локацию, где официально поддерживается Google AI Studio (например, США, Германия или любая страна Азии).
2. Перейдите на сайт aistudio.google.com под своей учетной записью Google.
3. Нажмите ‘Get API key’ в левом верхнем углу меню.
4. Выберите ‘Create API key in new project’. Скопируйте и сохраните ключ.

<a href="/images/articles/ai101-api/6.png" target="_blank">![Собака Павлова • Азбука AI • Как AI общаются с другими программами](~/assets/images/articles/ai101-api/6.png)</a>

## <a name="anchor1" />Как получить API-ключ для Deepseek
1. Залогиньтесь на сайте OpenRouter через Google, GitHub или email. 
2. Нажмите ‘Create API Key’ на странице ключей.
3. Назовите ключ.
4. Если есть поле лимита расходов, можно поставить минимальное значение или оставить по умолчанию (для бесплатной LLM).
5. Нажмите ‘Create’. Скопируйте ключ и сохраните.
